Getting started

  1. Enter chrome://extensions or edge://extensions in the address bar.
  2. Enable “Developer mode” and click “Load unpacked”.
  3. Select the extension folder containing manifest.json.
  4. Play a YouTube video, then open SideView from the browser’s extensions menu (the puzzle icon).
Automatic PiP help

In Chrome, open YouTube’s site settings using the icon next to the address and allow “Automatic picture-in-picture”, if available. Play a video with sound, then minimize the browser or switch tabs.

Availability depends on your browser version and settings. If no window appears, use the button above. Automatic PiP may not be available in Edge.
